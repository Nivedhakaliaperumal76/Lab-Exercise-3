# COMPARISON OF AMAZON AND FLIPKART

| UX Aspect           | Amazon                                                                                      | Flipkart                                                                           |
| ------------------- | ------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| **Homepage**        | Information-rich with recommendations, deals and categories. It can sometimes feel crowded. | Colourful and visually organized with prominent deals and categories.              |
| **Navigation**      | Provides deep navigation with many options and features.                                    | Simpler navigation and easier for new users.                                       |
| **Search**          | Detailed search with autocomplete and advanced filtering options.                           | Simple and user-friendly search with clear filtering options.                      |
| **Product Page**    | Provides extensive specifications, reviews, Q&A and recommendations.                        | Presents important product information in a cleaner and easier-to-scan format.     |
| **Filters**         | Provides many detailed filtering options.                                                   | Filters are comparatively simple and easy to understand.                           |
| **Visual Design**   | Functional and information-heavy.                                                           | Colourful, modern and visually engaging.                                           |
| **Personalization** | Strong personalized recommendations based on user activity.                                 | Provides personalized recommendations and category-based suggestions.              |
| **Cart**            | Feature-rich with several options and controls.                                             | Simple and straightforward cart experience.                                        |
| **Checkout**        | Efficient checkout with saved addresses, payment details and fast ordering options.         | Simple and relatively linear checkout process.                                     |
| **Error Handling**  | Provides useful error messages and recovery options.                                        | Provides basic error messages and recovery options.                                |
| **Accessibility**   | Provides several usability features and detailed product information.                       | Focuses on simple navigation and localized usability.                              |
| **Overall UX**      | Better suited for experienced users who require detailed information and advanced features. | Better suited for users who prefer simplicity, visual clarity and easy navigation. |

# OBSERVATIONS

## Amazon

### Advantages

* Powerful and detailed search functionality
* Extensive product information
* Large number of customer reviews
* Product Q&A section
* Strong personalization
* Efficient checkout process
* Detailed order tracking
* Extensive help and customer support
* Multiple filtering and sorting options

### Problems Identified

* Homepage can feel crowded
* Large amount of information may increase cognitive load
* Promotional elements can sometimes distract users
* New users may require time to understand all available options
* Product pages can contain excessive information
---

## Flipkart

### Advantages

* Clean and colourful interface
* Easy navigation
* Simple product discovery
* Clear call-to-action buttons
* Beginner-friendly shopping flow
* Visually attractive product presentation
* Comparatively simple filtering
* Easy-to-understand interface

### Problems Identified

* Some pages contain multiple promotional banners
* Certain product information may require additional navigation
* Search can be less precise for highly specific queries
* Some advanced features are less prominent
* Product details may not be as extensive as Amazon in some cases

# HEURISTIC EVALUATION SUMMARY

# A/B TESTING

### Version A – Existing Design
